# TRAIN WATCH 🚆

子どもと一緒に「もうすぐ電車が来る！」を楽しむための、つくばエクスプレス向けカウントダウンWebアプリです。

## 公開URL

https://ysatodat.github.io/train-watch/

## 主な機能

- TX01 秋葉原〜TX20 つくばの全20駅を選択
- 次の電車までを秒単位でカウントダウン
- 停車列車 / 通過列車（推定）の切り替え
- つくば方面 / 秋葉原方面の絞り込み
- 複数のお気に入り駅を localStorage に保存
- 3分前「そろそろ来るよ！」、30秒前「もう来るよ！」のお知らせ
- 始発駅では「そろそろ発車するよ！」表示
- 音・対応端末での振動
- Web Share APIでLINE / AirDrop等へ駅別URLを共有
- PWA対応・オフライン用Service Worker

## 時刻データについて

現在は土休日の日中運行パターンを中心としたβ版です。TX公式の駅・路線情報に掲載される種別別の標準所要時間と、研究学園駅で確認した土休日時刻を基に列車モデルを構成しています。通過駅の時刻は補間による推定であり、実際の運行・時刻表改正・遅延等とは差が出る場合があります。

公式情報: https://www.mir.co.jp/route_map/index.html
