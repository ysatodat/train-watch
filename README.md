# でんしゃくるよ！

**来る瞬間も、動く瞬間も。**  
子どもと一緒に、駅で電車を見る時間をもっと楽しくするWebアプリです。

## 使う

**https://ysatodat.github.io/train-watch/**

スマホのブラウザで開くだけ。アプリのインストールは不要です。

---

## どんなアプリ？

駅で子どもと電車を待っていると、気になるのは「あと何分で来る？」だけではありません。

- ホームへ入ってくる瞬間
- 停まる瞬間
- 停まっていた電車が動き出す瞬間
- 快速がビューンと通過する瞬間
- 上下線の電車がほぼ同時に来る、ちょっと珍しい瞬間

「でんしゃくるよ！」は、こうした**次の“見どころ”**を大きく表示します。

## 使い方は3つだけ

### 1. 駅をえらぶ
画面上部の駅名をタップして、いまいる駅を選びます。TX01 秋葉原〜TX20 つくばの20駅に対応しています。

### 2. 大きな表示を見る
次に起きる「到着・発車・通過」を1つだけ大きく表示します。近い時間に複数の電車が来るときは、その下に最大3本まで並びます。

### 3. 実際の電車を見る
「停まった！」「動いた！」「見えた！」が出たら、押して記録してもOKです。**押さなくてもアプリは時間に合わせて自動で次へ進みます。**

---

## ちょっと楽しいところ

### 発車する瞬間まで追える
電車がホームに来たあとも終わりではありません。停車中は、次の「動く瞬間」を見どころとして追います。

### 2本が近いと「ほぼ同時」
上下線など、別々の電車が近い時間に見どころを迎えると、同時に追えるように表示します。

### 今日見た本数を記録
「動いた！」「見えた！」などを押すと、その日の見た電車として端末内に記録します。

### お知らせ
ページを開いている間は、見どころの3分前・30秒前に音や振動で知らせることができます。

## 時刻について

このサービスは**乗換案内ではなく、電車を見るための参考ウォッチ**です。

現在のデータ版は **2026-08-23.3**、元となるダイヤは **2025年3月15日改正**です。時刻データは [`data/timetable.json`](./data/timetable.json) にまとめ、確認日時・取得元・平日/土休日の区別・2026年の祝日カレンダーも一緒に保存しています。

公共交通オープンデータセンターには、つくばエクスプレスの**駅時刻表・列車時刻表・GTFS・GTFS-RT（リアルタイム情報）**が公開されています。ただしAPI利用にはAPIキーが必要なため、公開GitHub Pagesへキーを埋め込まず、現在はバージョン付きの静的データを使用しています。

現状は、全20駅の日中を参考モデルで表示し、研究学園駅の深夜・早朝など一部は公開時刻表で確認した時刻を優先しています。研究学園駅の確認時刻は平日と土休日を分け、0〜3時台は前日の営業日の続きとして扱います。2026年の国民の祝日・休日も土休日ダイヤとして判定します。

通過・到着には推定を含み、遅延・運休・臨時列車は現在の静的版には反映されません。

詳しくは [`docs/data-sources.md`](./docs/data-sources.md) を参照してください。

## 安全について

このアプリより、**実際の電車と周囲の安全を優先してください。**

ホームでは黄色い線の内側など、安全な場所から楽しんでください。表示時刻は目安として利用し、列車の運行判断には使わないでください。

## プライバシー

お気に入り駅、表示設定、「今日見た電車」などはブラウザの `localStorage` に保存します。現時点でユーザーアカウントやサーバーへの行動履歴送信はありません。

---

## このアプリを作った理由

子どもと駅で電車を待っていて、

> 「来る時間は分かった。でも、停まっているこの電車はいつ動くんだろう？」

と思ったのがきっかけです。

電車を待つ数分や、動き出す一瞬まで、親子にとって小さなイベントになったらいい。そんな目的で作っています。
