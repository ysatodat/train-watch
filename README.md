# でんしゃくるよ！

**来る瞬間も、動く瞬間も。**  
子どもと一緒に、電車を見る時間をもっと楽しくするWebアプリです。

> **現在は、つくばエクスプレス（TX）と京成本線に対応した非公式ファンツールです。**  
> 各鉄道会社の公式アプリ・公式サービスではありません。

## 使ってみる

**https://ysatodat.github.io/train-watch/**

スマホのブラウザで開くだけ。インストールは不要です。

---

## どんなアプリ？

電車好きの子どもと眺めていると、楽しいのは「時刻表の何時何分」だけではありません。

- 電車が見えてくる
- ホームへ入ってくる
- 停まる
- 停まっていた電車が動き出す
- 通過列車がビューンと走る
- 2本の電車が近いタイミングでやってくる

「でんしゃくるよ！」は、そんな**次の見どころ**を大きく表示するためのアプリです。

## 使い方

### 1. 最初に、見る場所をえらぶ
初回だけ「どこで電車を見る？」から路線と駅を選びます。

現在の対応は、

- **TX**：秋葉原 TX01 〜 つくば TX20
- **京成**：京成本線 京成上野 KS01 〜 成田空港 KS42

です。

### 2. あとは大きな表示を見る
普段の画面では路線選択や駅一覧を出しっぱなしにしません。

画面上部には、たとえば **「TX · TX19 研究学園」** のように「いま見ている場所」だけを小さく表示し、その下をカウントダウンと電車の見どころに使います。

場所を変えたいときだけ、駅名部分を押して「見る場所を変える」を開きます。前に見たTX・京成の場所もここからすぐ戻れます。

### 3. 実際の電車を楽しむ
「停まった！」「動いた！」「見えた！」が出たら、押してもOKです。**押さなくても時間に合わせて自動で次へ進みます。**

電車が遅れてまだ来ていないときは「まだ来てない」を押すと、その電車をもう少し待ち続けられます。

## 2路線だけに絞っている理由

全国の鉄道を検索するアプリではなく、**実際にその場で電車を見る体験**を良くしたいからです。

路線ごとに特徴が違うので、共通UIを増やしすぎず、その路線だからできる体験を足していきます。

### TXでできること

TXは20駅の単一路線なので、路線全体を把握しやすく、次のようなTXならではの体験を入れています。

- 次に通過する「ビューン」の予告
- 上下線が近い「ほぼ同時」のタイミング
- 駅ごとに会えるTX車両の案内
- TX-1000 / 2000 / 3000系の車両ずかん

### 京成でできること

京成は路線網が大きいため、最初の対応範囲を**京成本線42駅**に限定しています。

京成側は公式の駅時刻表から静的データを生成し、停車する列車の発車時刻を中心に表示します。現在のβ版では、確実なデータがない通過列車を推測して「ビューン」と表示することはしません。

そのうえで京成ならではの楽しみとして、

- この駅に停まる**次のスカイライナー／モーニングライナー／イブニングライナー**
- **成田空港へ向かう注目列車**
- **京成 車両ずかん**：AE形、3200形、3100形、3000形を親子で見分けやすい4車種としてピックアップ
- 3700形、3600形、3500形（更新車）、3400形も「ほかの現役車両」として確認

を追加しています。

車両ずかんの実車写真はWikimedia Commonsの再利用可能な写真を利用し、作者・ライセンスをアプリ内にも表示しています。詳しくは [`docs/media-credits.md`](./docs/media-credits.md) を参照してください。

## デザインについて

このアプリは「鉄道会社の公式アプリっぽくする」ことではなく、**その路線を見ている気分が自然に伝わりつつ、親子が目の前の電車へ集中できること**を目指しています。

- TXは深い青緑を中心に、落ち着いた鉄道サインの印象
- 京成はコバルト系の青を中心に、TXとは自然に見分けられる印象
- **赤は通常のアクセントや「いま」の高揚感には使わず、実際の警告・エラー用に予約**
- 路線・駅選択は普段の画面に常駐させず、必要なときだけ開く
- モーダルはヘッダーを固定スクロールさせるのではなく、**ヘッダーとスクロール可能な本文を構造として分離**
- スマホのタップ領域は44px以上を基本にし、指が触れている間は領域全体を薄くハイライト
- タッチ操作でモーダルを開いた直後にCloseボタンへ不要なフォーカスリングを出さず、キーボード操作時はフォーカスを明示

公式ロゴをコピーして公式サービスと誤認させる表現はしていません。

TXのデザイン方針は [`docs/tx-design.md`](./docs/tx-design.md) にまとめています。

## お知らせ

ページを開いている間は、見どころの**3分前と30秒前**を画面表示・音・対応端末では振動で知らせることができます。

Safariを閉じた後に届くプッシュ通知ではありません。詳しい内容はアプリ内の「お知らせ」から確認できます。

## 時刻について

このサービスは**乗換案内ではなく、電車を見るための参考ウォッチ**です。

### TX

- 元となるダイヤ：2025年3月15日改正
- データ確認：2026年8月23日
- 研究学園駅の深夜・早朝など一部は公開時刻表で確認した時刻を優先
- 到着・通過には一部推定を含む

### 京成本線

- 公式駅時刻表を元に静的JSONを生成
- 確認したダイヤ改正：2025年12月13日
- 駅発時刻は公式時刻表由来
- 到着は発車時刻の少し前を目安として表示
- 通過列車は現在表示しない

どちらも遅延・運休・臨時列車を完全には反映できません。表示より、駅や列車の案内を優先してください。

データ取得元や更新方法は [`docs/data-sources.md`](./docs/data-sources.md) にまとめています。

## 安全について

このアプリより、**実際の電車と周囲の安全を優先してください。**

ホームでは安全な場所から楽しみ、表示時刻は目安として利用してください。列車の運行判断や乗換判断には使わないでください。

## プライバシー

見る場所、表示設定、「今日見た電車」、車両ずかんの「見つけた」記録などはブラウザの `localStorage` に保存します。現時点でユーザーアカウントやサーバーへの行動履歴送信はありません。

## このアプリを作ったきっかけ

たまたま泊まったホテルの部屋から、電車がよく見えました。

電車好きの息子が喜ぶので一緒に眺めていたのですが、

> 「次いつ来るんだろう？」  
> 「停まったけど、いつ動くんだろう？」

と思う場面が何度もありました。

**来る瞬間、停まる瞬間、動き出す瞬間。息子が喜ぶポイントを見逃したくない。**

それが「でんしゃくるよ！」を作ったきっかけです。

最初はそのとき見ていたTXだけでした。そこから「京成線もほしい」という声をもらい、現在はTXと京成本線の2つに対応しています。

路線を増やすこと自体を目的にせず、電車を見る数分や一瞬の動きが、親子にとって小さなイベントになることを大切にしています。
