# TXモードのデザインについて

「でんしゃくるよ！」は現在、**つくばエクスプレス（TX）と京成本線に対応した非公式の親子向け電車ウォッチ**です。この文書は、その中のTXモードでどのようにTXらしさを表現するかをまとめています。

## TXならではの体験

全国の鉄道UIをそのまま当てはめるのではなく、20駅・2方向・3車種というTX固有の特徴を体験に使います。

- TX01〜TX20の駅番号
- TX-1000 / 2000 / 3000系の車両ずかん
- 駅ごとに会える車種の違い
- 次の通過列車「ビューン」
- 上下線が近い「ほぼ同時」

路線・駅の選択自体は低頻度なので、通常画面には大きな路線切替を常駐させません。現在地だけをコンパクトに示し、必要なときだけ「見る場所を変える」を開きます。

## 色について

TX公式のコーポレート・アイデンティティでは、ブルー系を安全性・信頼性、カーマイン系を活気・エネルギーのコンセプトカラーとして説明しています。

公式情報:
https://www.mir.co.jp/company/ci.html

ただし、このアプリでは**赤を通常状態のアクセントには採用しません**。スマートフォンUIでは赤が警告・危険・エラーの意味として強く読まれやすく、親子で電車を楽しむ通常状態や「いま来た！」という高揚感と混同させたくないためです。

現在のTXモードは、深い青緑を基調にしています。

- Rail Teal: `#2F5D68`
- Deep Rail: `#214B55`
- Rail Sky: `#E6EFF0`
- Calm Green: `#4F7568`
- Warning / Error: `#B3261E`（必要な場合だけ）

「いま」の状態も青緑の濃淡で表現し、赤は実際の警告・エラーへ予約します。

## 公式アプリと誤認させない

このプロダクトはTX公式サービスではありません。アプリ全体として **「TRAIN WATCH · 非公式」** と明示し、現在地表示でTXを選択中であることを伝えます。以前の「TX専用・非公式」という表現は、京成本線対応後は使用しません。

TX公式のロゴマークや公式サイト掲載写真は、使用承認なしに転載しません。TX公式はロゴ・車両写真等の使用に事前承認が必要であることを案内しています。

https://www.mir.co.jp/inquiry/copyright.html

車両ずかんでは、再利用条件が明確なWikimedia Commons作品を使用し、作者・ライセンス・元ページをアプリ内に表示しています。詳細は [`media-credits.md`](./media-credits.md) を参照してください。

## デザイン原則

1. 駅番号を情報構造として使う
2. TXらしさはロゴ模倣ではなく、深い青緑・路線情報・時間表示でつくる
3. 高速性は派手な装飾ではなく、電車の動きと「ビューン」の体験で感じさせる
4. 赤は警告・エラーに予約し、通常の高揚感には使わない
5. 「公式っぽさ」より「親子で見て楽しい」を優先する
6. 文字を小さくして情報を詰め込まない
7. タップ領域は44px以上を基本にし、押している間は面で反応を返す
8. モーダルはヘッダーをstickyにせず、ヘッダーとスクロール本文を構造として分離する
9. 公式ロゴ・公式写真の転載に頼らない
