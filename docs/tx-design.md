# TX専用デザインについて

「でんしゃくるよ！」は現在、**つくばエクスプレス（TX）専用の非公式ファンツール**として設計しています。

## なぜTX専用なの？

全国の鉄道に広げる前提でUIを汎用化するより、いま実際に親子でTXを見ている状況に合わせて、20駅・2方向・3車種というTX固有の特徴を体験に使う方が、このプロダクトらしいと考えているためです。

そのため、画面には次のようなTX固有の表現があります。

- TX01〜TX20の駅番号
- 20駅を一本で見せる模式路線図
- TX-1000 / 2000 / 3000系の車両ずかん
- 駅ごとに会える車種の違い
- 次の通過列車「ビューン」
- 上下線が近い「ほぼ同時」

## 色について

TX公式のコーポレート・アイデンティティでは、コンセプトカラーとして次の2色が示されています。

- ブルーアドリアティック / 紺青色 — 安全性・信頼性
- カーマイン / 赤 — 活気・エネルギー

公式情報:
https://www.mir.co.jp/company/ci.html

このアプリでは、印刷用のDIC / PANTONE指定をそのままWebカラーとみなさず、画面上での可読性・コントラストを確認したうえで、近い印象のsRGB色へ調整しています。

- UI Blue: `#003B8F`
- UI Deep Blue: `#002B68`
- UI Red: `#E40046`

青は通常の操作・駅番号・路線の基調、赤は「いま」「現在駅」「見つけた」など、エネルギーが上がる瞬間へ限定して使います。

## 公式アプリと誤認させない

このプロダクトはTX公式サービスではありません。

そのため、アプリ内のヘッダーとフッターには **「TX専用・非公式」** と表示します。

また、TX公式のロゴマークや公式サイト掲載写真は、使用承認なしに転載しません。TX公式はロゴ・車両写真等の使用に事前承認が必要であることを案内しています。

https://www.mir.co.jp/inquiry/copyright.html

車両ずかんでは、再利用条件が明確なWikimedia Commons作品を使用し、作者・ライセンス・元ページをアプリ内に表示しています。詳細は [`media-credits.md`](./media-credits.md) を参照してください。

## デザイン原則

TXらしさを出すために、ロゴを模倣するのではなく、以下をプロダクト独自の文法として使います。

1. 駅番号を情報構造として使う
2. 青い路線と赤い現在地点で位置関係を見せる
3. 高速性は、派手な装飾ではなく電車の動きと時間表示で感じさせる
4. 通常状態は青、特別な瞬間だけ赤
5. 「公式っぽさ」より「親子で見て楽しい」を優先する
6. 文字を小さくして情報を詰め込まない
7. 公式ロゴ・公式写真の転載に頼らない
