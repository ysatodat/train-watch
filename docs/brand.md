# でんしゃくるよ！ Brand Foundation v2

## Brand
- Name: **でんしゃくるよ！**
- Descriptor: **TRAIN WATCH**
- Promise: **あと何秒？を、親子のワクワクに。**
- Role: 正確さを競う乗換案内ではなく、「次の電車を見る」体験を楽しく支える親子向けツール。

## Visual direction
**駅のサイン計画 × 少し温かい絵本**

デジタルSaaSのような「青白グラデーション・大きな角丸・ピル・強い影」を避ける。鉄道の案内表示のように秩序があり、同時に親子で使って冷たく感じないことを目指す。

### Avoid
- 画面全体を青系グラデーションにする
- すべてを大きな角丸カードに入れる
- あらゆる情報をpillで表現する
- 常設UIで絵文字を装飾として多用する
- すべての操作をelastic / bounceで動かす
- 太字900以上を画面全体で多用する

## Brand principles
1. **まっすぐ** — 子どもにも意味がわかる短い言葉。最重要情報を一番大きく。
2. **わくわく** — 電車が近づくほど少しだけ動きや色が増える。通常時は静かに。
3. **正直** — 推定時刻・遅延未反映・ページ内通知の制約を隠さない。
4. **あんぜん** — 操作より電車を見ることが主役。線路・ホームでは安全な場所から楽しむ。
5. **道具らしさ** — 触れるもの、選べるもの、現在地が一目でわかる。見た目より操作の確実さを優先する。

## Voice
### Child-facing
短く、肯定的、声に出して楽しい。
- 「そろそろ来るよ！」
- 「もう来るよ！線路を見よう！」
- 「いっしょに数えよう！」

### Parent-facing
簡潔で事実ベース。制約を曖昧にしない。
- 「時刻表ベースの参考表示です」
- 「お知らせは、このページを開いている間だけ動きます」

## Color v2
- **Rail Teal #244D55** — 主役。車両・鉄・案内表示の落ち着き。
- **Deep Rail #183A40** — 主要CTAと駅コード。
- **Paper #F3EFE6** — 背景。白すぎない紙の温かさ。
- **Surface #FBF8F1** — 主面。
- **Signal Vermilion #C9503D** — 30秒以内など強い注意。
- **Station Yellow #DFB14C** — ワクワク・お気に入り・接近予告。
- **Calm Green #5F7F6A** — 有効・安心。
- **Ink #252622** — 本文と数字。
- **Muted #716F68** — 補助情報。

色だけで状態を伝えず、必ず文言と組み合わせる。

## Shape
- Hero: radius 16–18px
- Standard control: radius 8–11px
- Small label: radius 5–6px
- Pillは原則使わず、必要な状態ラベルだけ小さな角丸矩形にする。
- Shadowは主役カードとDialogに限定。その他はborderで階層を作る。

## Typography
- 日本語システムフォントを基本とする。
- 通常本文 600–700、見出し 700–800。
- 極太はカウントダウンなど「1つの主役」に限定する。
- 英字の小見出しを装飾として乱用しない。

## Motion
- 通常操作: 70–200ms、power系ease、scale 0.985程度。
- 初回表示: 200–350msの短いfade/translate。
- 10秒前のみ数字の軽いpulseを許可。
- elastic / bounceは基本使わない。
- prefers-reduced-motionを尊重する。

## Design system foundation
- **Material Design 3** の情報階層・タッチターゲット・状態設計・アクセシビリティ原則を参照する。
- インタラクション部品は、iPhone Safariでの安定性を優先し、**native button / dialog / checkbox** を中心に実装する。
- デザインシステムは「見た目をそのまま借りる」のではなく、状態・アクセシビリティ・タップサイズのルールを借り、外観は本ブランドのトークンで構築する。
