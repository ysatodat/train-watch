# でんしゃくるよ！ Brand Foundation v3

## Brand
- Name: **でんしゃくるよ！**
- Descriptor: **TRAIN WATCH**
- Promise: **あと何秒？を、親子のワクワクに。**
- Role: 正確さを競う乗換案内ではなく、「次の電車を見る」体験を楽しく支える親子向けツール。

## Visual direction
**駅のサイン計画 × 親子の絵本**

鉄道案内のように迷わず読めて、絵本のように少し温かい。デジタルSaaSのテンプレートや、生成AIが初稿で作りがちな「青白・極小文字・カードだらけ・ピルだらけ」から距離を取る。

## Product design rules
1. **読めることを最優先** — 通常文16px、補助文14px、見える文字の最小13px。狭い画面では文字を縮めずレイアウトを変える。
2. **触れることが明確** — 主要タップ領域は44px以上。押せるものは見た目でも押せると分かる。
3. **面は1つ、情報はリスト** — Heroのみを主面として扱い、時刻一覧までカード化しない。
4. **装飾より意味** — 色、角丸、影、絵文字は状態や意味がある場合だけ使う。
5. **通常時は静か** — マイクロインタラクションは短く控えめ。接近10秒など感情価値の高い瞬間だけ少し強める。
6. **狭い画面で縮小しない** — 390px以下では2列を1列にするなど、文字サイズではなく構造で対応する。
7. **制約は正直に書く** — β、推定、遅延未反映、ページ内通知の制約を隠さない。

## Avoid
- 12px以下の常設テキスト
- 青白グラデーション
- すべてを大きな角丸カードに入れる
- あらゆる情報をpillにする
- 常設UIで絵文字を装飾として繰り返す
- すべての操作をelastic / bounceで動かす
- 画面全体をfont-weight 800以上にする
- 影だけで階層を作る
- 狭い画面で文字を縮めて解決する

## Brand principles
1. **まっすぐ** — 子どもにも意味がわかる短い言葉。最重要情報を一番大きく。
2. **わくわく** — 電車が近づくほど少しだけ動きや色が増える。通常時は静かに。
3. **正直** — 推定時刻・遅延未反映・ページ内通知の制約を隠さない。
4. **あんぜん** — 操作より電車を見ることが主役。線路・ホームでは安全な場所から楽しむ。
5. **道具らしさ** — 触れるもの、選べるもの、現在地が一目でわかる。見た目より操作の確実さを優先する。

## Voice
### Child-facing
短く、肯定的、声に出して楽しい。
- 「そろそろ来るよ！」
- 「もう来るよ！線路を見よう！」
- 「いっしょに数えよう！」

### Parent-facing
簡潔で事実ベース。技術用語を避ける。
- 「土休日ダイヤ（β）」
- 「参考時刻」
- 「お知らせは、このページを開いている間だけ動きます」

## Color v3
- **Rail Teal #244D55** — 主役。車両・鉄・案内表示の落ち着き。
- **Deep Rail #183A40** — 主要CTAと駅コード。
- **Paper #F4F0E6** — 背景。白すぎない紙の温かさ。
- **Surface #FFFDF8** — 主面。
- **Signal Vermilion #C04A36** — 30秒以内など強い注意。白文字とのAAコントラストを確保。
- **Station Yellow #D9AC45** — ワクワク・お気に入り・接近予告。
- **Calm Green #5A7663** — 有効・安心。
- **Ink #242722** — 本文と数字。
- **Muted #66645E** — 補助情報。Paper背景とのコントラストを4.5:1以上確保。

色だけで状態を伝えず、必ず文言と組み合わせる。

## Typography
- 日本語システムフォントを基本とする。
- Body: 16px / line-height 1.55。
- Secondary: 14px。
- Caption: 13pxを最小とする。
- Control label: 15–16px。
- Section title: 22px。
- Brand title: 20px。
- Countdown: 72px以上を基準に画面幅へ適応。
- 通常本文は500–600、操作・見出しは600–800。極太はカウントダウンなど主役に限定。
- 文字サイズの代わりに余白・色・太さで情報階層を作る。

## Shape
- Hero: radius 12px。
- Standard control: radius 6–8px。
- Status label: radius 4px。
- Pillは原則使わない。
- ShadowはHeroとDialogに限定。その他はborderと余白で階層を作る。

## Motion
- 通常操作: 70–200ms、power系ease、scale 0.985程度まで。
- 初回表示: 180–320msの短いfade/translate。
- 10秒前のみ数字の軽いpulseを許可。
- elastic / bounceは基本使わない。
- prefers-reduced-motionを尊重する。

## Accessibility baseline
- Apple HIGのiOS標準テキスト17pt・最小11pt、推奨コントロール44×44ptを最低基準として参照する。
- 本サービスは屋外・片手・親子利用を考慮し、HIGの最小値より大きい13pxを常設文字の下限とする。
- 色のコントラストはWCAG AAを基本とし、色だけで状態を伝えない。
- 200%程度の文字拡大でも主要操作が失われない構造を目指す。

## Design system foundation
- **Material Design 3** の情報階層・状態設計・アクセシビリティ原則を参照する。
- iPhone Safariでの安定性を優先し、**native button / dialog / checkbox** を中心に実装する。
- デザインシステムは外観をコピーせず、アクセシビリティ・状態・タップサイズ・情報階層の原則を借りる。
