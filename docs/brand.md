# でんしゃくるよ！ Brand Foundation

## Brand
- Name: **でんしゃくるよ！**
- Descriptor: **TRAIN WATCH**
- Promise: **あと何秒？を、親子のワクワクに。**
- Role: 正確さを競う乗換案内ではなく、「次の電車を見る」体験を楽しく支える親子向けツール。

## Brand principles
1. **まっすぐ** — 子どもにも意味がわかる短い言葉。最重要情報を一番大きく。
2. **わくわく** — カウントダウン・動き・色は、電車が近づくほど楽しくなる。
3. **正直** — 推定時刻・遅延未反映・ページ内通知の制約を隠さない。
4. **あんぜん** — 操作より電車を見ることが主役。線路・ホームでは安全な場所から楽しむ。

## Voice
### Child-facing
短く、肯定的、声に出して楽しい。
- 「そろそろ来るよ！」
- 「もう来るよ！線路を見よう！」
- 「いっしょに数えよう！」

### Parent-facing
簡潔で事実ベース。制約を曖昧にしない。
- 「時刻表ベースの参考表示です」
- 「お知らせは、このページを開いている間だけ動きます」

## Color
- **Sky Blue #1477FF** — 主役。空・TX・移動の爽快感。
- **Sun Yellow #FFD74A** — ワクワク、接近予告。
- **Go Coral #FF5D5D** — 30秒以内の強い注意。
- **Green #38B878** — 有効・安心・ON状態。
- **Ink #132238** — 本文と数字。
- **Cloud #F5F9FF** — 背景。

色だけで状態を伝えず、必ず文言・アイコンを併用する。

## Design system foundation
- **Material Design 3 Expressive**: 感情を生む色・形・モーション、適応的レイアウトの考え方を採用。
- **Web Awesome 3.11**: Button / Dialog / Switch とデザイントークンを利用。アクセシブルなインタラクションの土台にする。
- 独自ブランドは Web Awesome の semantic tokens と CSS custom properties で上書きする。
