# でんしゃくるよ！ Brand Foundation v4

## Brand
- Name: **でんしゃくるよ！**
- Descriptor: **TRAIN WATCH**
- Promise: **来る瞬間も、動く瞬間も。**
- Role: 正確さを競う乗換案内ではなく、「電車を見る」体験を楽しく支える親子向けツール。

## Design intent

目標は「AIっぽくなくする」ことではない。**現地で親子が使う状況を観察し、人が理由を持って決めたプロダクトにすること**。

見た目の流行やテンプレートからUIを組み立てず、次の順番で決める。

1. 駅で今、何を見たいか
2. 片手で何を押したいか
3. 一瞬で何が読めればいいか
4. そのために必要な文字・余白・動きだけを置く

Visual direction は **駅の情報板 × 親子の観察道具**。絵本らしい温度はコピーや電車の動きに持たせ、UI部品そのものを幼くしない。

## First-view rule

FVでは次の5つだけを主役にする。

1. いま見ている駅
2. 次の見どころ（到着 / 発車 / 通過）
3. 大きな時間表示
4. 短い一言
5. その瞬間だけ必要なら「停まった！ / 動いた！ / 見えた！」

時刻データの説明、設定、共有、お知らせの詳細はFVの主役にしない。道具としてHeroの外へ置く。

## Product design rules

1. **読めることを最優先** — 通常文16px、補助文14px、見える文字の最小13px。狭い画面では文字を縮めず構造を変える。
2. **現地操作を近くに置く** — その瞬間しか使わない操作は、その瞬間を見ている場所に出す。
3. **一番大事な情報は1つ** — Heroは次の見どころ1件。複数列車は下のリストで同時に追う。
4. **階層は文字組みと余白で作る** — 色面・影・角丸・チップを階層づくりの第一手段にしない。
5. **情報はリストとして見せる** — 時刻や複数列車を、カードの島へ分割しすぎない。
6. **押せるものと情報だけのものを混同しない** — 見た本数などはボタンのように見せない。
7. **通常時は静か** — モーションは状態理解を助ける範囲。電車が動く瞬間だけ感情価値を上げる。
8. **制約は正直に書く** — 推定、確認時刻、データ更新日、遅延未反映を隠さない。
9. **ユーザー入力は補助** — 「停まった！」「動いた！」を押さなくても状態は自動で進む。
10. **初見でも説明なしで使える** — それでも必要な説明は初回3ステップに隔離する。

## Avoid

以下は「AIっぽいから」ではなく、このプロダクトでは情報構造を曖昧にするため避ける。

- 左端の太いアクセント線だけで選択・重要度を示す
- ほぼ同じ角丸カードを縦に積み続ける
- 情報をすべてpill / chipにする
- 影で重要度を作る
- 青白グラデーションを画面全体に敷く
- 常設UIで絵文字を装飾として繰り返す
- すべての操作をbounce / elasticで動かす
- 狭い画面で文字を小さくして解決する
- 補助文を9〜12pxへ落とす
- 「説明したいこと」をFVへ全部置く
- 押せない情報をボタンのような箱に入れる

## Visual grammar

### Typography
- Body: 16px / line-height 1.55
- Secondary: 14px
- Caption: 13px minimum
- Control: 15–16px
- Section title: 20–22px
- Countdown: 72px以上を基準に適応
- 極太はCountdownなど1つの主役へ限定

### Shape
- Hero: 4px程度。大きなカード感より情報板に近づける。
- Standard control: 3–6px。
- リストは原則角丸なし。
- Dialogも6px程度。
- Pillは原則使わない。

### Lines
- 水平罫線を情報の区切りに使う。
- 選択状態を左アクセント線だけで表現しない。
- 現在行は面全体のごく薄いトーン差と文字ウェイトで表現する。

### Color
- Rail Teal `#244D55` — ブランドと主要操作
- Deep Rail `#183A40` — 強い操作・駅コード
- Paper `#F4F0E6` — 背景
- Surface `#FFFDF8` — Hero / Dialog
- Signal Vermilion `#C04A36` — 本当に注意が必要な瞬間
- Station Yellow `#D9AC45` — 特別な瞬間・お気に入り
- Ink `#242722` — 本文・数字
- Muted `#66645E` — 補助

色だけで状態を伝えない。

## Motion
- 通常操作: 70–200ms、短いfade / translate / scale 0.985まで
- Hero切替: 200–300ms
- 到着: 入ってきて減速
- 発車: 小さな予兆 → 実際に「動いた！」で加速
- 通過: 短く走り抜ける
- 10秒前: 数字のごく軽いpulse
- `prefers-reduced-motion` を尊重

## Voice

### Child-facing
短く、見たものとつながる言葉。
- 「きた！」
- 「停まった！」
- 「動く瞬間を待とう」
- 「ビューンと通るよ」

### Parent-facing
短く、事実ベース。
- 「確認時刻」
- 「目安」
- 「2026/8/23 データ確認」
- 「押さなくても自動で進みます」

## Accessibility baseline
- 主要タップ領域44×44px以上
- 常設文字13px以上、通常文16px
- WCAG AAを基本
- 色だけに状態を依存しない
- 毎秒変わるCountdownを無闇に`aria-live`へ入れない
- VoiceOverでnative button / dialogの意味を保つ
- 文字拡大時は縮小ではなく改行・1列化で対応

## Design-system stance

Apple HIG / Material Design 3は、外観のテンプレートとしてではなく、**可読性・タップ領域・状態設計・アクセシビリティの基準**として参照する。

部品はiPhone Safariでの確実性を優先し、native button / dialog / checkboxを中心にする。
