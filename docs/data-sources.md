# 時刻データについて

「でんしゃくるよ！」は、電車を見る体験を楽しくするための参考ウォッチです。乗換案内や運行判断を目的としたサービスではありません。

## 現在のデータ版

- データ版: **2026-08-23.3**
- 確認日時: **2026-08-23 00:51 JST**
- 元となるダイヤ: **2025年3月15日改正**
- 祝日カレンダー: **2026年 内閣府公表分**
- このスナップショットのカレンダー有効期限: **2026-12-31**
- アプリが読むファイル: [`data/timetable.json`](../data/timetable.json)

時刻だけでなく、確認日時・取得元・平日/土休日・祝日・どこまでが確認時刻でどこからが参考モデルかを同じJSONに保存しています。

## 現在のカバー範囲

### 全20駅
日中の列車は、種別ごとの停車駅と駅間所要時間をもとにした参考モデルです。

### 研究学園駅（TX19）
深夜・早朝の一部時刻は公開時刻表で再確認した値を優先しています。**平日と土休日を別データとして保持**しています。

鉄道の深夜時刻はカレンダー日そのままではなく、前日の営業の続きとして考える必要があります。そのため、このアプリでは **4:00を営業日の境界**として扱います。たとえば火曜0:20は月曜の平日ダイヤ、月曜0:20が日曜深夜に当たる場合は土休日ダイヤとして判定します。

2026年については、土日に加えて内閣府が公表する「国民の祝日・休日」も土休日ダイヤとして扱います。

終電後は巨大な分数カウントを出さず、次の始発を案内します。

### 通過・到着
公開時刻が分単位であることや、通過時刻が直接掲載されないケースがあるため、到着・通過には推定を含みます。発車も秒単位の時刻が分からない場合は「発車の時間帯」として扱います。

## 公開されているデータ源

### つくばエクスプレス公式時刻表
TX公式サイトから、各駅の時刻表・列車別時刻表へアクセスできます。

- TX公式: https://www.mir.co.jp/route_map/index.html
- 研究学園駅: https://www.mir.co.jp/route_map/kenkyu-gakuen/
- 時刻表サービス: https://transfer-train.navitime.biz/tx

### 祝日
2026年の国民の祝日・休日は内閣府公表情報を使用しています。

- 内閣府「国民の祝日について」: https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html

### 公共交通オープンデータセンター（ODPT）
つくばエクスプレスについて、次のようなデータセットが公開されています。

- 駅時刻表 JSON
- 列車時刻表 JSON
- GTFS / GTFS-JP
- GTFS-RT（リアルタイム列車情報）

代表的なデータセット:

- 駅時刻表: https://ckan.odpt.org/dataset/r_station_timetable-mir
- GTFS-RT: https://ckan.odpt.org/dataset/r_train_gtfs_rt-odpt_train-mir

ODPT APIの利用には開発者登録とAPIキーが必要です。

## なぜ今はGitHub PagesからODPT APIを直接呼ばないの？

このアプリは静的なGitHub Pagesで公開しています。ブラウザJavaScriptにAPIキーを書いてしまうと、利用者からキーを閲覧できてしまいます。

そのため、現在は **APIキーを公開しないことを優先して、バージョン付き静的JSONを正本にする** 方式です。

`data/timetable.json` を見れば、どの時点のデータを使っているかが分かります。

## 今後の更新方法

ODPT APIを本格利用する場合は、Cloudflare Workerなどのサーバーレス環境にAPIキーを秘密情報として保存し、次の構成へ移行する想定です。

1. サーバー側だけがODPT APIへアクセスする
2. 駅時刻表・列車時刻表を定期取得する
3. アプリ用JSONへ正規化して保存する
4. `checkedAt` とデータ版を更新する
5. 祝日カレンダーも年次更新する
6. 必要な場面だけGTFS-RTを使い、遅延・列車位置などのリアルタイム情報を追加する

こうすることで、APIキーを利用者へ公開せず、最新データへ更新できます。

## データの見せ方のルール

アプリでは、データの確度に応じて次のように扱います。

- **確認時刻**: 公開時刻表で確認した時刻
- **時刻表**: 静的ダイヤとして保持している時刻
- **目安**: 駅間所要時間などから推定した到着・通過
- **発車の時間帯**: 分単位の発車時刻しか分からず、秒を断定できない場合

実際の列車と現地案内を常に優先してください。
