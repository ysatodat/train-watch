# 時刻データについて

「でんしゃくるよ！」は、電車を見る体験を楽しくするための参考ウォッチです。乗換案内や運行判断を目的としたサービスではありません。

現在は **つくばエクスプレス（TX）** と **京成本線** の2系統を扱います。路線ごとに取得できるデータの性質が違うため、無理に同じ精度へ揃えず、分かることだけを表示します。

## TX

### 現在のデータ版

- データ版: **2026-08-23.3**
- 確認日時: **2026-08-23 00:51 JST**
- 元となるダイヤ: **2025年3月15日改正**
- 祝日カレンダー: **2026年 内閣府公表分**
- このスナップショットのカレンダー有効期限: **2026-12-31**
- アプリが読むファイル: [`data/timetable.json`](../data/timetable.json)

時刻だけでなく、確認日時・取得元・平日/土休日・祝日・どこまでが確認時刻でどこからが参考モデルかを同じJSONに保存しています。

### カバー範囲

全20駅の日中列車は、種別ごとの停車駅と駅間所要時間をもとにした参考モデルです。

研究学園駅（TX19）の深夜・早朝の一部時刻は公開時刻表で再確認した値を優先し、**平日と土休日を別データとして保持**しています。

鉄道の0時台は前日の営業日の続きとして扱う必要があるため、このアプリでは **4:00を営業日の境界**としています。2026年については、土日に加えて内閣府公表の国民の祝日・休日も土休日ダイヤとして扱います。

公開時刻が分単位であることや、通過時刻が直接掲載されないケースがあるため、到着・通過には推定を含みます。

### 公開データ源

- TX公式: https://www.mir.co.jp/route_map/index.html
- 研究学園駅: https://www.mir.co.jp/route_map/kenkyu-gakuen/
- TX時刻表サービス: https://transfer-train.navitime.biz/tx
- ODPT 駅時刻表: https://ckan.odpt.org/dataset/r_station_timetable-mir
- ODPT GTFS-RT: https://ckan.odpt.org/dataset/r_train_gtfs_rt-odpt_train-mir
- 内閣府「国民の祝日について」: https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html

ODPT APIの利用には開発者登録とAPIキーが必要です。GitHub PagesのクライアントJavaScriptへAPIキーを埋め込まないため、現在はバージョン付き静的JSONを正本にしています。

## 京成本線

### 現在の対応範囲

- 路線: **京成本線**
- 駅: **KS01 京成上野〜KS42 成田空港の42駅**
- 確認したダイヤ改正: **2025年12月13日**
- 駅カタログ: [`data/keisei-main-stations.json`](../data/keisei-main-stations.json)
- 時刻スナップショット: [`data/keisei-main.json`](../data/keisei-main.json)

### 取得方法

京成公式の駅時刻表ページを、GitHub Actions上の同期スクリプト [`scripts/inspect-keisei.mjs`](../scripts/inspect-keisei.mjs) で読み取り、アプリ用の静的JSONへ正規化します。

ブラウザから利用者ごとに京成サイトへアクセスする方式ではありません。

生成時には、

- 取得日時
- ダイヤ改正日
- 駅番号・駅名
- 平日 / 土休日
- 方面
- 発車時刻
- 列車種別
- 行先

を保存します。

初回検証では、京成本線42駅から **平日11,078件・土休日10,468件** の駅発時刻を取得できることを確認しています。

### なぜ京成では「通過」を出さないの？

現在取得しているのは駅時刻表なので、その駅に停車する列車の発車時刻は分かりますが、通過する列車の時刻は分かりません。

そのため、京成β版では通過列車を推測して表示しません。

- 発車: 公式駅時刻表由来
- 到着: 発車時刻の少し前を「目安」として表示
- 通過: 現在は表示しない

という方針です。

京成公式の駅時刻表: https://keisei.ekitan.com/naritaacs-i/timetable

## なぜ路線ごとに方式が違うの？

「全国の鉄道を同じロジックで扱う」より、**その路線で確実に取得できる情報を使って、現地で見る体験を壊さないこと**を優先しているからです。

データ構造は複数路線へ拡張できるよう分離していますが、利用者向けUIには内部構造をそのまま出しません。普段の画面では現在の「見る場所」だけを表示し、路線や駅を変えるときだけ選択UIを開きます。

## データの見せ方のルール

アプリでは確度に応じて、次のように扱います。

- **確認時刻**: 公開時刻表で確認した時刻
- **時刻表**: 静的ダイヤとして保持している時刻
- **目安**: 駅間所要時間や発車時刻から推定した到着・通過
- **発車の時間帯**: 分単位の発車時刻しか分からず、秒を断定できない場合

遅延・運休・臨時列車は完全には反映できません。実際の列車と現地案内を常に優先してください。
